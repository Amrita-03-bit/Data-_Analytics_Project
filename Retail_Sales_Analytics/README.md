# Retail Sales Analytics Project



## 1. Project Overview

This project focuses on analyzing retail business data using Python, MySQL, SQL, Pandas, NumPy, and Data Visualization.

The objective is to explore sales performance, customer behavior, product performance, employee performance, and business trends through data analysis and visualization.

## 2. Dataset

The project contains six tables:

- Customers
- Employees
- Products
- Orders
- Order Items
- Payments

## 3. Tools & Technologies

- Python
- MySQL
- SQL
- Pandas
- NumPy
- SQLAlchemy
- Data Visualization

## 4. Business Questions

### A. Sales Performance Analysis

1. How does monthly revenue change over time?
2. Which month generates the highest and lowest revenue?
3. How does the number of orders change over time?
4. How does daily sales performance vary throughout the week?
5. What is the cumulative revenue generated by the business over time?
6. How does monthly revenue compare with the previous month?
7. How does the average order value change over time?
8. What is the distribution of revenue across different months?

### B. Product Performance Analysis

9. Which are the top 10 products based on total revenue?
10. Which are the top 10 best-selling products based on quantity sold?
11. Which products generate the lowest revenue?
12. How does product price relate to the quantity sold?
13. Which product categories contribute the most to total revenue?
14. How does the quantity sold compare with revenue generated by each product?
15. Which products have high sales quantities but relatively low revenue?
16. How does product performance vary across different months?
17. Which products show similar sales patterns over time?

### C. Customer Analysis

18. Who are the top 10 customers based on total spending?
19. Which customers place the highest number of orders?
20. How is customer spending distributed across the business?
21. How does customer spending vary across different customer groups?
22. What is the relationship between the number of orders and total spending?
23. Which customers contribute the largest share of total revenue?
24. How does customer purchasing behavior vary over time?

### D. Employee Performance Analysis

25. Which employees handle the highest number of orders?
26. Which employees generate the highest sales revenue?
27. How does employee-wise revenue compare with the number of orders handled?
28. How does employee performance vary across different months?

### E. Order & Payment Analysis

29. What is the distribution of orders across different order statuses?
30. Which payment methods are used most frequently?
31. How much revenue is collected through each payment method?
32. How does order value vary across different payment methods?
33. What is the distribution of order values across all orders?
34. How do order values vary across different product categories?
35. How does the relationship between order quantity and order value change across payment methods?

### F. Statistical & Relationship Analysis

36. Is there a relationship between product price and revenue?
37. Is there a relationship between order quantity and total order value?
38. How do order values differ across product categories?
39. How does the distribution of order values vary across payment methods?
40. Are there unusual or extreme values in the order amounts?
41. How do different sales variables relate to each other?



## 5. Project Workflow

1. Connect Python with MySQL.
2. Retrieve data using SQL queries.
3. Perform data analysis using Pandas and NumPy.
4. Create and customize visualizations.
5. Save visualizations in the outputs folder.
6. Generate meaningful business insights.
