# Food Delivery Business Analytics

## Project Overview

This project simulates a real-world Data Analyst assignment for a food delivery company.

The company has provided a relational database containing customer, restaurant, order, order-item, payment, and delivery information.

The objective is to analyze the business data, answer business questions, and produce meaningful business findings.

## Database

**Database Name:** `food_delivery_db`

### Tables

* `customers` — customer information
* `restaurants` — restaurant information
* `orders` — order-level information
* `order_items` — items purchased in each order
* `payments` — payment information
* `deliveries` — delivery performance information

## Tools Used

## Business Questions

### Basic Business Analysis

1. Count the total number of customers.
2. Count the total number of restaurants.
3. Count the total number of orders.
4. Find the number of unique cities represented in the customer data.
5. Find the number of restaurants in each city.
6. Find the number of customers in each city.
7. Find the earliest order date.
8. Find the latest order date.
9. Find the number of delivered and cancelled orders.
10. Check whether any table contains duplicate primary-key values.

### Customer & Restaurant Analysis

11. Display customer name, order ID, order date, and order status.
12. Display order ID, customer name, restaurant name, and restaurant city.
13. Find the total number of orders placed by each customer.
14. Find the total amount spent by each customer.
15. Identify the highest-spending customer.
16. Find the total revenue generated by each restaurant.
17. Identify the highest-revenue restaurant.
18. Find the total quantity of food items sold for each item.
19. Identify the most frequently purchased item.
20. Find the average order value.

### Advanced Business Analysis

21. Find customers who placed more than 5 orders.
22. Find restaurants whose revenue is greater than the average restaurant revenue.
23. Find the cancellation rate for each restaurant.
24. Identify restaurants with the highest cancellation rate.
25. Find each customer's first order date.
26. Find each customer's most recent order date.
27. Rank restaurants by revenue within each city.
28. Find the Top 3 restaurants in each city.
29. Find the percentage contribution of each restaurant to total revenue.
30. Calculate month-over-month revenue.

### Python / Pandas Analysis

31. Bring a useful SQL result into Pandas and inspect the DataFrame.
32. Check missing values.
33. Check duplicate records.
34. Convert date columns to datetime.
35. Create an `order_value` column where appropriate.
36. Analyze customer spending distribution.
37. Find the highest-value customers.
38. Analyze restaurant performance using Pandas.
39. Analyze delivery-time statistics by restaurant.
40. Identify unusually high delivery time.
41. Compare average order values across cities.

### Final Business Findings

42. What city generates the most revenue?
43. Which restaurants are major revenue contributors?
44. What proportion of orders are cancelled?
45. Which payment method is used most often?
46. Which customers are high-value?


## Final Deliverable

The final project should contain:

The final findings should be supported by the analysis results.
