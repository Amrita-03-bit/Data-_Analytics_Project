# Retail Store Operations & Inventory Analytics

## Project Overview

This project analyzes the operations of a retail company using sales, products, stores, employees, suppliers, inventory, returns, and expenses data.

The main purpose of this project is to understand the business from different perspectives such as:

* Sales performance
* Revenue and profit
* Store performance
* Product performance
* Inventory management
* Product returns
* Employee contribution
* Supplier performance
* Operating expenses
* Business trends over time

The project focuses on answering real-world business-analysis questions using data.

## Database

**Database Name:** `retailOperationsDB`

## Tables Used

1. `stores`
2. `products`
3. `suppliers`
4. `employees`
5. `sales`
6. `inventory`
7. `returns`
8. `expenses`
