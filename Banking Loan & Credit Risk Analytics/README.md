# Banking Loan & Credit Risk Analytics

## Project Overview

This project simulates a real-world Data Analyst assignment for a banking company.

The company has provided a relational database containing customer, loan, payment, and branch information.

The objective is to analyze the banking data, answer business questions, identify credit-risk patterns, and produce meaningful business findings.

## Database

**Database Name:** `bankingRiskDB`

### Tables

* `customers` — customer information
* `loans` — loan-level information
* `payments` — payment information
* `branches` — branch information
* `loan_branches` — relationship between loans and branches

## Tools Used

## Business Objective

The analysis focuses on:

* Customer credit profiles
* Loan portfolio performance
* Loan approval and rejection patterns
* Loan defaults
* Payment behavior
* Branch performance
* Loan-type performance
* High-value customers
* High-risk customers
* Business trends
